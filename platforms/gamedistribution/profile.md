# GameDistribution

## Operational summary

- Use the GameDistribution-specific build and SDK adapter when required.
- Upload the expected ZIP/package format, not a build directory intended for another portal.
- Complete the portal checklist and Change Log before requesting activation.
- Keep Draft, In Review, Active, Published, and public behavior as separate states.

## Sources

- Quality guidelines: https://developer.gamedistribution.com/quality-guidelines
- Developer portal: https://developer.gamedistribution.com/games

Requirements are volatile and must be rechecked before each upload or activation request.
