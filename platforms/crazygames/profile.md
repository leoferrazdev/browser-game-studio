# CrazyGames

## Operational summary

- Keep a CrazyGames-specific build and adapter.
- Validate the intended Basic Launch or Full Launch stage against current documentation.
- Run the Preview Tool/QA before submission.
- Keep the initial package small and test desktop and mobile behavior.
- Do not treat local SDK mocks as proof of portal approval.

## Sources

- Requirements: https://docs.crazygames.com/requirements/intro/
- SDK: https://docs.crazygames.com/sdk/intro/

Requirements are volatile and must be rechecked before each submission.
